# massive-design을 디자인 시스템으로 쓰고, 노선 색과 도착 트랙은 앱에 둔다

화면 UI를 shadcn/ui 기본 테마 + 하드코딩 Tailwind 색에서 `@flameware/ui`·`@flameware/tokens`(massive-design)로 옮기기로 했다. 범용 요소(카드, 배너, 배지, 버튼, 스켈레톤, 텍스트)는 디자인 시스템의 컴포넌트와 시맨틱 토큰만 쓰고, 정보를 담은 시각 요소인 노선 유형별 노선 색, 노선 번호 배지, 도착 트랙, 당겨서 새로고침은 wherebus 안에 앱 전용으로 둔다. 노선 색은 실제 버스 표지와 같은 의미를 가지므로 디자인 시스템 팔레트나 브랜드 색으로 바꾸지 않으며, 같은 이유로 브랜드 색은 노선 색(일반 초록)과 겹치지 않도록 디자인 시스템 기본 파랑을 그대로 쓴다.

## Consequences

- 패키지가 GitHub Packages(비공개)에 있어 로컬과 배포 환경 모두 `read:packages` 토큰이 필요하다.
- 범용인데 디자인 시스템에 없는 요소(Alert의 액션 칸, 당겨서 새로고침)는 일단 앱에서 조립하고, 다른 앱에서 반복될 때 massive-design으로 올린다.
